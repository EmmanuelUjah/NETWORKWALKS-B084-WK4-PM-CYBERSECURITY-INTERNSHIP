 # 🔐PENETRATION TESTING PROJECT (Mediroza Hospital)

# 📌 Project Overview:
The Mediroza Hospital project was an authorized cybersecurity assessment and capstone project that provided hands-on experience in reconnaissance, network scanning, vulnerability assessment, web application security, password auditing, and security reporting. Using tools such as Kali Linux, Nmap/Zenmap, DIG, Nessus, Burp Suite, and John the Ripper, the project demonstrated a structured and ethical approach to identifying, analyzing, documenting, and recommending remediation for potential security weaknesses.

# 🎯 Objectives:
To assess the security of the Mediroza Hospital environment by identifying potential vulnerabilities, evaluating associated risks, and recommending appropriate security measures to strengthen its overall cybersecurity posture.

# Purpose of the Lab
To gain practical cybersecurity experience by performing an authorized security assessment, identifying vulnerabilities, and recommending measures to improve the security of the Mediroza Hospital environment.
